# GGST キャラ対策ノート

Guilty Gear -Strive- の相手キャラ別対策をまとめ、自分用メモ・試合ログ・練習メニューを記録する非公式ファンツール。
静的ファイルのみで動作し、GitHub Pages でそのまま公開できます。

## 機能
- **対策**：相手キャラの特徴と対策の基本。自キャラが A.B.A の時は「アバ視点」の方針（立ち回り / JRゲージ運用 / 注意点）も表示
- **メモ**：組み合わせごとに 立ち回り / 確定反撃 / 警戒する技 / 起き攻め / その他 を自動保存、体感難易度★
- **フレーム**：相手の「まず警戒する技」と、Dustloop から取り込んだフレームデータの表（ガード後 −5 以下を強調）
- **練習**：キャラごとの練習チェックリスト（共通＋固有＋自分で追加）
- **試合ログ**：勝敗・日付・原因タグ（対空できず／投げ抜け失敗 など）・ひとことメモ
- **分析**：勝率、直近の流れ、原因タグの集計、相手キャラ別の勝率
- **一覧**：自キャラ視点で全キャラの難易度・試合数・勝率・練習進捗を並び替え
- **データ管理**：JSON バックアップ / 復元、Dustloop JSON の取り込み、カスタムキャラの追加

## フレームデータの取り込み
データ管理タブに表示される Dustloop Cargo API の URL をブラウザで開き、JSON を保存して読み込みます。
`where=chara="..."` を変えるとキャラを選べ、`where` を省略して `limit=5000` にすると全キャラ分を一括で取り込めます。

## 構成
- `index.html` / `style.css` / `app.js`
- `data/characters.js` … キャラ一覧と相手にした時の対策
- `data/aba.js` … A.B.A 視点の対策
- `data/drills.js` … 練習メニュー
- `data/frames.js` … 警戒技リストとフレームデータ（初期は空）

データはブラウザの localStorage に保存されます。攻略メモは一般的な目安です。正確な数値は Dustloop 等で確認してください。

## Dustloop から一括取得（ネットワーク許可がある環境で）
```
python3 scripts/fetch-dustloop.py      # 全キャラ取得 → data/frames.js に埋め込み
python3 build-artifact.py --full out.html
```

## 動画シュリンク（`video-shrink.html`）
対戦リプレイの録画をブラウザ内で軽くする単体ページ。mp4/mov は WebCodecs の高速モード（再生を待たずにデコード→縮小→エンコード、音声はそのままコピー）、それ以外や非対応ブラウザは Canvas + MediaRecorder の実時間モードで処理します（送信なし）。
