# ドット絵メーカー

ブラウザだけで動くピクセルアートエディタです。`index.html` を開くか、GitHub Pages で公開して使えます。

## 描く
- ペン / 消しゴム / 塗りつぶし / スポイト / 直線 / 四角 / 円
- 左右・上下ミラー描画、反転・回転・ずらし、輪郭線の自動追加
- 8〜128px のキャンバス（ゲームキャラ向けの縦長サイズもあり）、元に戻す/やり直す

## ゲームキャラ
- フレーム（コマ）の追加・複製・削除・並べ替え、前のコマを薄く表示（オニオンスキン）
- アニメーションのプレビュー（1〜24fps）
- 勇者・スライムのテンプレート

## 画像からドット絵
- 画像を選ぶ・ドロップ・貼り付けで読み込み、指定サイズに縮小してドット化
- 自動減色（色数指定）または PICO-8 / ファミコン / ゲームボーイ風などのパレット
- コントラスト・鮮やかさ調整、ディザリング、背景の透明化、輪郭線の追加

## 保存
- PNG（1コマ）、スプライトシート PNG（全コマ横並び）、GIF アニメ（背景透過、等倍〜×16）
- 作業内容はブラウザに自動保存
