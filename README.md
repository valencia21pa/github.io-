# GGST キャラ対策ノート

Guilty Gear -Strive- の相手キャラ別対策をまとめ、自分用メモと戦績を記録する非公式ファンツール。
`index.html` 1ファイルで動作し、GitHub Pages でそのまま公開できます。

## 機能
- 自キャラ・相手キャラを選んで、相手キャラの特徴と対策の基本を表示
- キャラ組み合わせごとのメモ（立ち回り / 確定反撃 / 警戒する技 / 起き攻め / その他）
- 体感難易度（★1〜5）と勝敗数の記録、勝率表示
- 自キャラ視点の対キャラ一覧（難易度・試合数・勝率で並び替え）
- 共通知識（FD・バースト・RC など）のまとめ
- JSON でのバックアップ / 復元、カスタムキャラの追加

データはブラウザの localStorage に保存されます。
