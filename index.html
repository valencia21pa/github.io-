    クラウド保存：確認中…

    メモ・試合ログ・戦績は、ブラウザ内とアーティファクトのクラウド保存の両方に保存されます。別の端末で開いても同じ内容になります。

    バックアップ

    メモ・戦績・試合ログ・チェックはこのブラウザ内に保存されます。別端末へ移す時やバックアップにはJSONを書き出してください。

    ランクマ戦績を取り込む（Puddle Farm）

    Puddle Farm の自分のプレイヤーページ（例：puddle.farm/ggst/player/【ID】/AB）を Chrome で「名前を付けて保存」（.mht か .html）して読み込むか、ページ全体をコピーして下に貼り付けてください。セット単位で取り込まれ、同じ時刻のセットは重複しません。

    フレームデータを取り込む（Dustloop）

    Dustloop の Cargo API から書き出した JSON を読み込みます。ブラウザで下のURLを開いて「名前を付けて保存」し、そのファイルを選んでください。chara= の部分を変えるとキャラを選べます（複数回読み込めば追加されます）。全キャラ一括は where を省略して limit=5000 にしてください。
